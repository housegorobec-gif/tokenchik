# Токенчик 🤖👓

Маленький робот в очках, который живёт в боковой панели Claude Code / Claude Desktop и помогает тратить меньше токенов.

## Что он делает

- Показывает заполнение контекста, текущую модель, примерную стоимость сессии (оценка, не счёт) и лимиты подписки (5 часов и неделя) со временем сброса.
- Меняет настроение: зелёный — всё экономно, синий — есть идеи, жёлтый — токены утекают, красный — тревога (плюс всплывающее уведомление).
- Даёт советы с кнопками:
  - контекст ≥ 50% (тревога с 80%) → **/compact**;
  - лимит ≥ 75% → перейти на **Sonnet** или **Haiku**;
  - один ход добавил > 25k токенов → читать файлы частями, искать через grep;
  - на Opus три коротких ответа подряд без инструментов → хватит Sonnet;
  - пауза больше часа при большом контексте → кэш остыл, сначала /compact;
  - больше 40 ходов без сжатия → новая задача с чистого листа (**/clear**);
  - три и больше субагентов → простой поиск лучше делать напрямую.
- Показывает другие сессии за сутки с контекстом ≥ 50%.
- Любой совет можно скрыть кнопкой «Не сейчас».

Панель открывается сама при отправке сообщения или командой `/tokenchik-panel`.

## Установка

В терминальной сессии Claude Code:

```
/plugin install tokenchik --marketplace housegorobec-gif/tokenchik
```

На вопрос о добавлении маркетплейса ответьте `y`, затем выберите область установки.

Из командной строки:

```
claude plugin install tokenchik --marketplace housegorobec-gif/tokenchik
```

Для Claude Desktop можно просто положить папку плагина в `~/.claude/skills/tokenchik` — она загрузится в новых сессиях.
